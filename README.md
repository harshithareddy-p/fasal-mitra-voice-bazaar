# Fasal Mitra – Voice Bazaar

Fasal Mitra is an AI-powered voice-based platform designed to help farmers
understand market information and make better decisions about selling their crops.

## 🚀 Live Demo

https://fasal-mitra-voice-bazaar--25rh1a05fy.replit.app

## ✨ Features

- Voice-based interaction
- Farmer-friendly interface
- Telugu language support
- AI-powered responses
- Crop and market assistance
- Simple and accessible design

## 🛠️ Tech Stack

- AI / LLM
- Voice Processing
- Web Application
- Telugu Language Support
- Replit

## 🎯 Problem

Farmers may face difficulties understanding market information,
prices, and available selling options.

## 💡 Solution

Fasal Mitra provides a simple voice-first interface where farmers
can interact with the system in their preferred language.
